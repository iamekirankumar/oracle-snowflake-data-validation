# Oracle-to-Snowflake Data Validation Framework

## 📌 Project Overview
A sample data validation project demonstrating how to validate data during migration from Oracle to Snowflake.

The objective is to ensure data accuracy, consistency, and completeness between source and target systems.

## 🎯 Validation Scenarios

1. **Record Count Validation** – Compare source and target record counts.
2. **Duplicate Validation** – Identify duplicate records.
3. **NULL Validation** – Check mandatory columns for NULL values.
4. **Data Reconciliation** – Compare source and target records.
5. **Column-Level Validation** – Validate column values and data types.
6. **Primary Key Validation** – Verify uniqueness and integrity.

## 🛠️ Technologies
- SQL
- Oracle
- Snowflake

## 📂 Project Structure

- `sql/` – Sample validation queries
- `test_data/` – Dummy source and target datasets
- `docs/` – Project documentation

## 🔍 Expected Outcome
Identify missing, duplicate, mismatched, and inconsistent records between source and target systems.

## ⚠️ Disclaimer
This project uses sample scenarios and dummy data. No company-owned data or confidential scripts are included.
